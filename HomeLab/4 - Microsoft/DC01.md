# DC01 Setup
We will proceed with the installation of Windows Server 2022, it is mostly like installing any Windows OS. I have chosen to install it with the GUI to make it easier to me to manage.

## Network Configuration
We will firstly set the network configuration of the server, which will be a static IP:

- IP: 10.10.20.21 ~~192.168.0.21~~
- DNS: 10.10.20.1 ~~192.168.0.21~~
- Gateway: 10.10.20.1 ~~192.168.0.1~~

![](attachments/Pasted%20image%2020260531015233.png)

## Roles installation
After setting up the network configuration, we will install the roles so the server can act what we want it to act. In this case, since the point of this project is to run an AD, we will install:

- Active Directory Domain Services (AD DS)
- DNS Server

To do so, we must open `Server Manager` and in `Manage` we select `Add Roles and Features Wizard`, we proceed with the wizard, we select `Role-Based or...` and we select our server.

Now we must select the Server Roles and install the Features: 

![](attachments/Pasted%20image%2020260531015749.png)

We continue with the wizard and we wait for it to install all.

## Promote to Domain Controller
After installing the role, in `Server Manager` we can see a warning that requires us to promote this server to a domain controller, we just click on it.

It opens up a wizard, we must select `Add a new forest` to create one and assign it a root domain name, in this case `jn.clydehl.local`.

It then ask us to assign a password for Directory Services Restore Mode (Will learn what is that later on).

After we assign a NetBios Name, in this case JNCLYDEHL.

![](attachments/Pasted%20image%2020260531021856.png)

We follow the wizard and if the `Prerequisites Check` goes well we can finish the  promotion
## Result

![](attachments/Pasted%20image%2020260602153205.png)

After the promotion, `DC01` becomes the first Domain Controller in the forest and the Active Directory database is created. DNS is also automatically integrated with AD and our domain becomes active.
# DNS Configuration

DNS is critical for Active Directory functionality because all domain services rely on name resolution.

![](attachments/Pasted%20image%2020260602153654.png)
## DNS server configuration.

After installation, DC01 acts as the authoritative DNS Server for the domain. The DNS role is automatically integrated with Active Directory.

### DNS Setting on DC01

- Preferred DNS: 192.168.0.21  
- No external DNS is used directly by clients

## DNS Forwarders

Forwarders are configured to allow external domain resolution (internet access).  
  
Configured forwarders:  
- 1.1.1.1
